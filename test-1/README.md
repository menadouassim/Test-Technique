# Test-Technique

    This is a test-app to scrape the hackernews website and export a csv that contains :
        -the news headline
        -the link it points to
        -the number of up-votes 

# To-run :

## set-up venv:
    mac : python3 -m venv env 

## activate venv:
    mac : source env/bin/activate

## install requirements:
    pip install -r requirements.txt

## run the scraper: 
    cd test-1/hackernews && python scraper.py
