# Test-Technique


    this is the second part of the test-technique ,
    it represents the simple api calling of the a tool called saleserp


# to-run:

## set up a venv :

    python -m venv env

    source env/bin/activate

## install requirements:

    pip install -r requirements.txt

## set-up the API_KEY:

    create the .env and copy the .env.example in it and put in your API-KEY

## run the script:

    cd test-2 
    python main.py
